# Sécurité

## Surface

Le script lit un CSV local, envoie des requêtes DNS de type MX (noms de domaine seulement) et écrit deux CSV. Il n'ouvre aucune connexion SMTP et n'appelle aucun service tiers. La surface concerne surtout des données personnelles (listes d'adresses) : voir [docs/PRIVACY_AND_SECURITY.md](docs/PRIVACY_AND_SECURITY.md).

## Signaler un problème

Le signalement privé de GitHub (« Report a vulnerability ») n'est pas activé sur ce dépôt. Ouvrir une [issue](https://github.com/RAAAAAGEEEEE/email-prefilter/issues/new) intitulée « Sécurité » **sans détail exploitable** ni adresse réelle ; le mainteneur répondra pour convenir d'un canal privé.

## Versions concernées

Seule la dernière version publiée (voir [CHANGELOG.md](CHANGELOG.md)) reçoit des correctifs.
